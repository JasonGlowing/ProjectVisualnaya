# Smart Task Planner

AI-powered task planner built with FastAPI and SQLite.

## Features

- CRUD for tasks
- AI task categorization
- AI time estimation
- Swagger/OpenAPI docs
- Pytest unit tests

## Run

```bash
pip install -r requirements.txt
uvicorn app.main:app --reload
```
