# AI Assistant Log

## Prompt 1

Создай простой backend-проект Smart Task Planner на FastAPI + SQLite в одном файле.

## Реакция ИИ

ИИ предложил использовать FastAPI, SQLAlchemy и SQLite.  
Для простоты вся логика была помещена в один файл `main.py`.

## Prompt 2

Добавь автокатегоризацию задачи по описанию.

## Реакция ИИ

ИИ предложил функцию `guess_category()`, которая определяет категорию по ключевым словам.

## Prompt 3

Добавь оценку времени выполнения задачи.

## Реакция ИИ

ИИ предложил функцию `estimate_minutes()`, которая оценивает время по сложности и длине описания.

## Prompt 4

Упрости проект, чтобы он запускался без OpenAI API ключа.

## Реакция ИИ

Настоящий AI API был заменен на локальную имитацию AI-логики.  
Это делает проект проще для запуска и демонстрации.
